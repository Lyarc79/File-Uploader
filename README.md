# File Uploader

A full-stack web application for file drive management built with **Node.js**, **Express**, **PostgreSQL (Supabase)**, **Prisma**, and **EJS**, following the **MVC architecture**

## Key Features

- **MVC Architecture:** Structured routes, controllers, views, and Prisma ORM database queries.
- **Authentication & Authorization:** Secure sign-up, login, and session persistence using Passport.js and Prisma Session Store.
- **Folder Management:** Create, rename, and delete custom folders to organize files.
- **Folder Sharing:** Generate temporary, time-bound share links allowing unauthenticated users to view shared folders.
- **Cloud Storage & File Operations:** File upload handling via Multer and Supabase Storage with file metadata display (name, size, type, upload date), direct downloading, and deletion.
